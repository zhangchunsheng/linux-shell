Linux 常用命令速查

文件操作

  • ls -l - 详细列表
  • cd 目录 - 切换目录
  • cp 源 目标 - 复制文件
  • mv 源 目标 - 移动文件
  • rm 文件 - 删除文件

文本处理

  • grep 模式 - 搜索文本
  • awk '{print}' - 文本分析
  • sed 's/a/b/' - 文本替换
  • cat 文件 - 查看文件

系统管理

  • ps aux - 查看进程
  • kill PID - 终止进程
  • df -h - 磁盘空间
  • free -m - 内存使用

网络

  • ssh user@host - 远程登录
  • curl URL - 发送请求
  • wget URL - 下载文件
  • ping host - 测试连接
